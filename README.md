<h1>Skacząca Kaczuszka (Duck Jump)</h1>

<h3>Prosta gra 2D stworzona w C++ z wykorzystaniem biblioteki SFML.</h3>

Gracz steruje skaczącą kaczuszką, której celem jest wspinanie się jak najwyżej po platformach i zdobywanie jak najlepszego wyniku.

### Opis gry

W grze sterujesz kaczuszką, która automatycznie spada pod wpływem grawitacji. Twoim zadaniem jest:

- skakać po platformach,

- unikać spadnięcia poza ekran,

- zbierać walutę w postaci chlebków,

- zdobywać jak największą wysokość i wynik.

Chlebki stanowią walutę w grze i są elementem systemu progresji.

Waluta – Chlebki
Podczas rozgrywki gracz może zdobywać chlebki, które w przyszłości posłużą do:
- odblokowywania nowych postaci,
- personalizacji rozgrywki.

Aktualnie wszystkie postacie są dostępne od razu do wyboru.

### Technologie
- C++
- SFML (Simple and Fast Multimedia Library)
